# KONT — Lig & Kupa Yöneticisi

تطبيق أندرويد احترافي لإدارة الفرق والدوريات والكؤوس والبطولات.

A professional Flutter app for building **real** football competitions on Android: teams, leagues, cups, World Cup, Champions League, Swiss, and group stages.

## ما تغيّر / Yenilikler

- واجهة أندرويد كاملة: شريط تنقل سفلي، معالج إنشاء متعدد الصفحات، شاشات متجاوبة.
- أصبح نطاق التطبيق واضحاً ومركزاً: الفريق يتكوّن من **اسم وأيقونة فقط**، والبطولات تدير النتائج والجدولة دون إدارة فردية.
- إصلاح أخطاء إنشاء البطولة (Stepper القديم كان يتخطى الخطوة الأخيرة في الكأس).
- 8 صيغ واقعية بدل 3 أنواع ناقصة:
  1. **Tek Devre Lig** — كل الفرق ضد بعضها مرة واحدة
  2. **Çift Devre Lig** — ذهاب وإياب (Süper Lig / Premier Lig)
  3. **Kupa (Tek Maç)** — خروج مغلوب، باي تلقائي، الجولة التالية تلقائية
  4. **Rövanşlı Eleme** — مباراتان ومجموع الأهداف ثم ركلات ترجيح
  5. **Grup Turnuvası** — مجموعات مستقلة مع جداول نقاط
  6. **Dünya Kupası** — مجموعات ثم خروج مغلوب
  7. **Şampiyonlar Ligi** — مجموعات ثم إقصاء ذهاب/إياب والنهائي مباراة واحدة
  8. **Swiss / Sabit Maç** — كل فريق يلعب N مباريات
- جدول النقاط يحترم إعدادات الفوز/التعادل/الخسارة.
- محرك جدولة Berger (circle method) مع أيام الراحة وعدم تعارض نفس اليوم.
- حفظ كامل للأحداث والأهداف والضربات الترجيحية.
- إعدادات متقدمة لكل بطولة: التقدم التلقائي، وقت الراحة، الوقت الإضافي، ركلات الترجيح، القرعة، ومباراة المركز الثالث.
- خريطة bracket للكأس تعرض الأعمدة حسب الجولة، المواجهات، الباي، نتائج الرجلين، والمتأهلين.
- إعدادات دخول متقدمة للكأس: كل الفرق من أول مرحلة، أو تحديد دخول كل فريق من دور 64/32/16 أو ربع النهائي أو نصف النهائي، مع التحقق من صحة توزيع الفرق.
- Seribaşı/تصنيف القرعة يحافظ على ترتيب الفرق ويمنع المواجهات المبكرة غير المرغوبة، مع توليد الباي تلقائياً للفرق التي تدخل لاحقاً.
- مركز موسم وتحليلات: تقدم البطولات، المباريات القادمة، نتائج الفرق وإحصاءات عامة.
- إعدادات تطبيق كاملة: الوضع الفاتح/الداكن/النظام، محاكاة المباريات، تأكيد النتائج، البطاقات المضغوطة.
- نسخ احتياطي واستعادة JSON محلياً، مع حماية من البيانات الفاسدة والتحقق من النتائج والجدولة.

## التشغيل على أندرويد

المتطلبات: Flutter 3.22+ و Android SDK.

```bash
flutter create . --platforms=android
flutter pub get
flutter run
```

أو من Android Studio: افتح المجلد وشغّل التطبيق على جهاز/محاكي.

معرّف الحزمة: `com.ligplanlayici.kont`

## الاستخدام

1. من تبويب **Takımlar** أضف اسم الفريق واختر أيقونته فقط.
2. من **Ligler** أنشئ دوريًا أو كأسًا واختر الصيغة الواقعية.
3. أدخل النتائج من **Canlı** أو من مركز المباراة.
4. في الكأس تظهر خريطة الأدوار والمتأهلين، وتُولَّد الجولة التالية تلقائياً بعد اكتمال الجولة الحالية.
5. من **Ayarlar** خصّص المحاكاة، التأكيد، الثيم، وجدولة الراحة، أو خذ نسخة JSON احتياطية.
